# Code Review

This code review walks through the Contact Service, the single Java artifact used across all three enhancement categories, before any of the enhancements were made. It covers what the code does, an analysis of its strengths and weaknesses, and the plan for enhancing it in each of the three categories: Software Design and Engineering, Algorithms and Data Structures, and Databases.

## Course Outcomes Referenced in the Review

The video references the five Computer Science program outcomes by number. Here is what each one means:

- **Outcome 1, Collaboration:** building environments where people with different backgrounds can work together and support decision making, shown through things like clear commit history and in-code comments that let a teammate follow your reasoning.
- **Outcome 2, Communication:** delivering professional-quality written, oral, and visual communication that fits the audience it's for, the same skill this review, the narratives, and this ePortfolio itself are all meant to demonstrate.
- **Outcome 3, Algorithmic design:** designing and evaluating solutions using sound algorithmic principles, and weighing the trade-offs between different design choices instead of picking whichever one is fastest to write.
- **Outcome 4, Tools and techniques:** using well-founded, appropriate tools and techniques to actually deliver value, not something that merely happens to run.
- **Outcome 5, Security:** anticipating how a system could be misused during design, so vulnerabilities get caught and mitigated before they become real problems, and data stays private and secure.
